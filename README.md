# Madurai Finance — Flutter Mobile Application

A production-ready loan-lifecycle mobile application (**Apply → Review → Approve → Disburse → Repay via UPI → Collect → Export RPS Statements**) built with Flutter. It connects directly to the Madurai Finance PHP REST API backend and MySQL database, enforcing role-based access control (**Financier**, **Collection Agent**, **Customer**, **Security**, **Data Entry Operator**).

### 🚀 Version 2.3.0 (Latest Release) — *Color Theme Fix, PDF Fixes, Firebase Deployment*

#### Color Theme Fixes
- **Fixed Material 3 blue color bleed ([main.dart](lib/main.dart)):** Replaced `ColorScheme.fromSeed()` with explicit `ColorScheme` mapping all color slots to the green palette. This eliminates unexpected blue/indigo tones generated by Material 3's seed algorithm that appeared on login screens and other widgets.
- **Login screen backgrounds verified:** Both `staff_login_screen.dart` and `customer_login_screen.dart` confirmed using `AppGradients.hero` (deep green gradient) matching the home page.

#### PDF Export Fixes
- **Fixed access denied error on Android ([rps_export_service.dart](lib/services/rps_export_service.dart)):** Removed direct file writes to `/storage/emulated/0/Download` which required `MANAGE_EXTERNAL_STORAGE` permission. PDF and HTML now save to the app's temp directory (`getTemporaryDirectory()`) and open via the system share/print dialog — no permissions needed.
- **Removed rupee symbol (₹) from PDF headers:** The hardcoded `₹` in table headers was showing as cross boxes (tofu) because the PDF built-in font lacks the glyph. Table headers now use plain text labels (Opening, Principal, Interest, EMI, Closing).
- **Added `formatMoneyNumeric` helper ([utils.dart](lib/core/utils.dart)):** New function that formats numbers with commas but without the ₹ symbol, used exclusively in PDF generation to avoid font rendering issues.
- **Rounded all money values:** Changed `formatMoney` default parameter from `round: false` to `round: true`. All currency displays across the entire app now show rounded integer values without decimals.

#### Firebase Integration
- **Firebase project created:** New Firebase project `madurai-finance` with Android app registered (`com.example.madurai_finance_app`).
- **FlutterFire configured ([firebase_options.dart](lib/firebase_options.dart)):** Auto-generated Firebase configuration file for the Android platform.
- **Firebase Core initialized ([main.dart](lib/main.dart)):** Added `firebase_core` dependency and `Firebase.initializeApp()` in `main()`.
- **Firebase App Distribution:** APK v1.0.0 uploaded to App Distribution.
  - **Console:** https://console.firebase.google.com/project/madurai-finance/appdistribution/app/android:com.example.madurai_finance_app/releases/5q3b41f7edf3g

## ⚡ Building & Deployment Guide

### 1. Run in Development
```bash
$env:JAVA_HOME = "C:\src\jdk-17"
flutter pub get
flutter run
```

### 2. Build Release APK
```bash
$env:JAVA_HOME = "C:\src\jdk-17"
flutter build apk --release --no-tree-shake-icons
```
The compiled Release APK will be generated at:
`build/app/outputs/flutter-apk/app-release.apk`

### 3. Deploy to Firebase App Distribution
```bash
firebase login
firebase appdistribution:distribute "build\app\outputs\flutter-apk\app-release.apk" \
  --app "1:875176998844:android:789a9459c1d463caa3ddb9" \
  --release-notes "v1.0.0 - Release notes here"
```

- **App Distribution:** https://console.firebase.google.com/project/madurai-finance/appdistribution

## 🔐 API Endpoints Used

Auth uses PHP's native session cookie (`dio_cookie_manager`), maintaining state across all backend requests:

| Screen(s)                         | Endpoint              | Description |
|------------------------------------|-----------------------|-------------|
| Public Loan Application            | `rates.php`, `apply.php` | Fetch rate cards & submit new application |
| Staff Login                        | `login.php`           | Authenticate staff credentials |
| Customer Login                     | `customer_login.php`  | Authenticate via Phone + DOB/PAN |
| Session Restore / Logout           | `session.php`, `logout.php` | Session management |
| Dashboard (All Roles)              | `bootstrap.php`       | Central dashboard data fetch |
| Loans List / Detail / Approve      | `loans.php`           | Manage loans & approval workflows |
| Applications Review                | `applications.php`    | Review customer loan applications |
| Collections List + Record Payment  | `collections.php`     | Track & record payment collections |
| Users List / Create / Toggle       | `users.php`           | User account administration |
| Audit Log                          | `audit.php`           | View system audit trail |
